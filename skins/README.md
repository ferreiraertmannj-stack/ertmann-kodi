# Ertmann Skins

Skins oficiais da Ertmann Tech para o Kodi.

## Estrutura planejada

```text
skins/
  skin.ertmann/     Skin principal da distribuição Ertmann
```

## Convenções

- Skins usam a engine nativa do Kodi (XML + texturas).
- Devem funcionar sem alteração no core do Kodi.
- Compatibilidade com Kodi Nexus e Omega.
- Resolução mínima suportada: 720p.
