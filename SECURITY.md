# Security Policy

## Supported versions

The project is pre-release. Security fixes are assessed for the latest
development version only until a stable release policy is published.

| Version | Supported |
| --- | --- |
| 0.x | Yes, development only |
| < 0.1.0 | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub Private
Vulnerability Reporting when it is enabled for the repository, or contact an
Ertmann Tech maintainer through a private channel.

Include a clear description, affected version, reproduction steps, impact, and
any proposed mitigation. Maintainers will acknowledge the report, assess its
impact, and coordinate a fix before public disclosure.
