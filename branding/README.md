# Branding

Assets visuais e de identidade do Ertmann Media Center.

## Conteúdo planejado

- `splash.jpg` — Splash screen (substituirá `kodi-source/media/splash.jpg`)
- `icon*.png` — Ícones em múltiplas resoluções
- `banner.png` — Banner da aplicação
- `vendor_icon.png` — Ícone do vendor
- `vendor_logo.png` — Logo do vendor

## Regras

- Não utilizar a marca "Kodi" em nenhum asset de branding.
- Manter proporções compatíveis com os assets originais do Kodi.
- Formatos: JPEG para splash, PNG para icons e logos.
