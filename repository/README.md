# Ertmann Tech Repository

Estrutura declarativa do futuro repositório oficial de add-ons da Ertmann Tech.
Não publica, instala, atualiza ou baixa conteúdo nesta etapa.

## Arquivos

- `addon.xml`: manifesto do add-on de repositório instalado no Kodi.
- `addons.xml`: índice de add-ons e versões que estarão disponíveis para o Kodi.
- `addons.xml.md5`: placeholder do arquivo que será gerado em cada release.
- `docs/repository.md`: modelo de publicação, versionamento e integridade.
- `docs/github-actions.md`: fluxo planejado de automação de releases.
- `resources/`: diretório reservado para recursos declarativos futuros.

## Estado atual

As URLs em `addon.xml` são placeholders e não apontam para serviço ativo.
Nenhum ZIP, release, ação GitHub ou mecanismo de atualização foi criado.
